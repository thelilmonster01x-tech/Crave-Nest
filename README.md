# 🍴 Crave Nest

### Good Food. Real Cravings. Better Moments.

**Crave Nest** is a personal UI/UX and front-end development project created to explore how a modern food brand can deliver an engaging, visually appealing, and user-friendly digital experience.

The project focuses on combining **creative branding, modern UI/UX principles, responsive web design, and interactive front-end development** into a single-page food website.

---

## 🎯 About the Project

I created Crave Nest as a personal project to improve and demonstrate my skills in:

* UI/UX design
* Front-end development
* Responsive web design
* Brand identity
* Interactive web experiences
* HTML, CSS, and JavaScript

The goal is to create a food brand website that feels **modern, welcoming, energetic, and visually appetizing** while remaining simple and easy to navigate.

---

## ✨ Features

* 🎨 Modern food-focused UI
* 📱 Fully responsive design
* 🍔 Food categories and featured meals

## 🚀 Running the Project

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/crave-nest.git
```

Navigate into the project:

```bash
cd crave-nest
```

Then open `index.html` in your browser.

For development, I recommend using **Visual Studio Code with Live Server**.
